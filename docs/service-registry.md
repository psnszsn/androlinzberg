hosted one (`src/framework/android/app/SystemServiceRegistry.java`); regenerate after a
phase changes either. A *real* hosted client is the verbatim AOSP class from the built
framework jar (over a hosted service or, where AOSP tolerates it, over no service); a
*stub* client is a `src/framework-stubs` replacement; *not registered* means
`getSystemService` returns null on this host.
